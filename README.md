# Bash skriptimine

See repositoorium sisaldab Bash skriptimise harjutusi, näiteid ja õppematerjale.

## Kaustastruktuur

* **`for-tsüklid/`** – Korduslaused ja tsüklid kindla arvu iteratsioonidega.
* **`while-tsüklid/`** – Tingimuslikud korduslaused.
* **`tsüklid-ja-case/`** – Valikumenüüd ja tingimuslikud harunemised (`case` laused).
* **`sissehitatud-tsüklid/`** – Käsurea argumentide töötlemine ja sisseehitatud muutujad.
* **`php-paigaldus/`** – Serveri seadistuse ja PHP paigalduse automatiseerimise skriptid.

## Kasutamine

Skriptide käivitamiseks veendu, et neil oleks käivitusõigus:

```bash
chmod +x kaustanimi/skript.sh
./kaustanimi/skript.sh
